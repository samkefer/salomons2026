# reproducibility_template
Template to use for reproducibility projects in PSYCH 251

Original_Paper: 
- PDF of Salomons et al., 2026
  
Data Folder:
- RawData.xlsx downloaded from supplementary material of Salomons et al., 2026
- CleanedData.xlsx modification of RawData.xlsx with ID matching from a non-public sheet
- Cleaned Tests Folder with separate .csv files for each task from CleanedData.xlsx
- data_dictionary.numbers for binary tests and unsolvable test measures

Writeup Folder:
- Reproducibility Report Template.qmd with write-up and code
- Reproducibility-Report-Template.pdf rendered version of Reproducibility Report Template.qmd
- Images Folder with saved .png files from Reproducibility Report Template.qmd
